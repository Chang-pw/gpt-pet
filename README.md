# ChatGPT Pet Prototypes

This workspace currently contains two prototype directions:

- `extension/`: a browser extension that attaches a small pet above the ChatGPT send button
- `src/` + `src-tauri/`: an earlier desktop pet experiment with Tauri and Three.js

## Recommended next step

If you want the pet to live directly on `chatgpt.com`, start with the extension prototype:

1. Open your browser extensions page
2. Enable developer mode
3. Load unpacked:
   - `/Users/zbw/Documents/New project/extension`

Detailed instructions live in [extension/README.md](/Users/zbw/Documents/New%20project/extension/README.md).
